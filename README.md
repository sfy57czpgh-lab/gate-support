# GATE Support

Static Support and Privacy Policy pages for **GATE: Seal the Unknown**, intended for GitHub Pages and App Store Connect.

Planned public URLs:

- Support: https://shoito.github.io/gate-support/
- Privacy Policy: https://shoito.github.io/gate-support/privacy.html

## Before publishing

The official support email used by both pages is `philadelphiarocketcompany@gmail.com`.

## GitHub Pages setup

1. Create a GitHub repository named `gate-support`.
2. Push these files to the `main` branch.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch** as the source.
5. Select the `main` branch and `/ (root)` folder.
6. Save the settings and verify both published URLs.

The site uses only static HTML and CSS. It has no JavaScript, analytics, cookies, build step, or external font dependency.
